# Online Reservation System

## Project Overview

The Online Reservation System is a Java desktop application that allows users to log in, reserve train tickets, view booking confirmations, and cancel reservations.

## Technologies Used

* Java
* Java Swing
* MySQL
* JDBC
* IntelliJ IDEA

## Features

* User login
* Train reservation
* Passenger details entry
* PNR generation
* Booking confirmation
* Ticket cancellation using PNR
* MySQL database connectivity

## Project Structure

* `src/com/reservation/database` — Database connection and testing
* `src/com/reservation/gui` — Login, reservation, cancellation, dashboard, and confirmation screens
* `src/com/reservation/dao` — Data access classes
* `src/com/reservation/model` — Model classes

## How to Run

1. Install JDK and MySQL.
2. Create and configure the required MySQL database and tables.
3. Update database connection settings in `DBConnection.java`.
4. Open the project in IntelliJ IDEA.
5. Run the `Main` class.
