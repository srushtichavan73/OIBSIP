# ATM Interface

## Project Overview

The ATM Interface is a console-based Java application that simulates basic ATM operations. The project demonstrates Object-Oriented Programming (OOP), user authentication, account management, transactions, and collection handling.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)

## Features

- Account number login
- PIN verification
- Maximum 3 PIN attempts
- Check account balance
- Deposit money
- Withdraw money
- Transfer money between accounts
- Transaction history
- Transaction receipt
- Balance validation
- Insufficient balance handling
- Multiple user accounts
- Quit option
